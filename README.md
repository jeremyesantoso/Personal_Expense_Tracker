# 💰 Full-Stack Personal Expense Tracker

A lightweight, full-stack web application designed to track, manage, and calculate daily expenses in real-time. Built as a portfolio project to master RESTful API architecture, backend-to-database communication, and dynamic frontend DOM manipulation.

---

## 🚀 Features

- **Create Expenses:** Easily log new expenses with a description, category, and dollar amount.
- **Live Total Calculation:** Automatically computes and updates the cumulative total sum of all logged records in real-time.
- **Persistent Storage:** Data is securely saved, retrieved, and deleted from a local MySQL database via connection pooling.
- **Delete Records:** Remove unwanted entries with instant UI synchronization.
- **XSS Protection:** Includes input sanitization helpers to secure DOM rendering.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Backend:** Node.js, Express.js
- **Database:** MySQL (managed via XAMPP / phpMyAdmin)
- **Database Driver:** `mysql2` (supporting connection pooling and async/await)
